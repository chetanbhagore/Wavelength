# 🌊 Wavelength

> **Not who you follow. Who you're in sync with, right now.**
> A synchronous, ephemeral social space built without user profiles, follower counts, popularity algorithms, or permanent chat logs.

## ✨ Features

- 🎛️ **Frequency Dial**: Interactive, spring-physics circular dial that tunes into 8 real-time emotional frequencies (e.g. *Can't sleep, mind's racing*, *New city, no friends yet*, *Quietly proud of myself today*).
- 🌊 **Ambient Waveform Canvas**: Real-time generative sine-wave backdrop that shifts hues dynamically to match the current frequency mood.
- 📡 **Radar Sync**: Radial scan pulse with participant synchronization animations connecting you with strangers.
- 💬 **Ephemeral Synchronous Rooms**: 12-minute live rooms (with instant **90s Demo Mode** toggle) featuring pseudonymous strangers (`stranger_XX`). No chat histories are saved.
- ✨ **Resonance Interaction**: Tap any message to trigger an ambient glow bloom and feed into the collective room resonance meter. Zero competitive like counts.
- 🪞 **Ritual Echo Modal**: Leave a single-line reflection (~80 characters) behind for the next visitors before the room dissolves.
- 🌌 **The Echo Wall**: A chronological, collective memory stream filterable by frequency chips. No ranking algorithms or upvote sorting.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm 9+

### Installation & Local Development
```bash
# Clone the repository
git clone https://github.com/chetanbhagore/Wavelength.git

# Navigate to project directory
cd Wavelength

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit **`http://localhost:5173`** in your browser.
